# Holocron Archive

Holocron Archive는 Star Wars 관련 작품 정보와 최신 소식을 제공하는 데이터베이스 기반 큐레이션 웹서비스입니다.  
Star Wars 콘텐츠를 주제로 한 뉴스, 작품 정보, 이미지, 카테고리 정보를 PostgreSQL 데이터베이스에 저장하고, Flask 기반 웹 애플리케이션을 통해 사용자가 검색 및 탐색할 수 있도록 지원합니다.

## 프로젝트 개요

본 프로젝트는 데이터베이스를 사용하는 웹 서비스 프로토타입 개발을 목표로 합니다.  
Star Wars 관련 작품 정보와 최신 기사 데이터를 수집 및 정리하여 PostgreSQL에 저장하고, 사용자는 웹 화면을 통해 최신 소식과 작품 정보를 확인할 수 있습니다.

현재 프로토타입은 Star Wars 데이터를 중심으로 구성되어 있으며, `franchise` 속성을 통해 Marvel 등 다른 프랜차이즈로 확장 가능한 구조를 가지고 있습니다.

## 주요 기능

### 1. 프랜차이즈 탭 선택

Star Wars, Marvel 등 여러 프랜차이즈로 확장 가능한 탭 구조를 제공합니다.  
현재는 Star Wars 데이터를 중심으로 구현되어 있으며, DB의 `franchise` 컬럼을 기준으로 데이터를 구분합니다.

### 2. 최신 소식 조회

Star Wars 관련 기사와 소식을 최신순으로 확인할 수 있습니다.  
가장 최신 기사는 대표 카드로 크게 표시하고, 나머지 기사는 2열 카드 형태로 출력합니다.

각 기사에는 다음 정보가 포함됩니다.

- 기사 제목
- 한국어 제목
- 출처
- 게시일
- 카테고리
- 요약
- 한국어 요약
- 대표 이미지
- 원문 URL

### 3. 기사 검색 및 카테고리 필터링

사용자는 키워드를 입력하여 기사 제목, 한국어 제목, 요약, 한국어 요약, 출처명을 검색할 수 있습니다.  
또한 영화, 드라마, 애니메이션, 게임, 도서, 기타 카테고리를 기준으로 기사를 필터링할 수 있습니다.

### 4. 작품 정보 조회

영화, 시리즈, 애니메이션 등 Star Wars 작품 정보를 확인할 수 있습니다.  
작품 정보에는 다음 항목이 포함됩니다.

- 작품명
- 작품 유형
- 공개일 또는 개봉일
- 공개 상태
- 작품 설명
- 작품 이미지
- 관련 링크

작품 정보 페이지는 다음과 같은 구조로 구성됩니다.

- 개봉 예정작 슬림 바
- 현재 화제작 대표 카드
- 나머지 작품 2열 카드 목록

### 5. 화제작 강조

현재 상영 중인 대표 작품은 별도의 화제작 카드로 강조됩니다.  
화제작 카드는 일반 작품 카드보다 크게 표시되며, 딥 네이비와 골드 계열 포인트 색상을 사용하여 시각적으로 구분합니다.

### 6. 보러 가기 기능

작품 상태에 따라 다른 방식의 이동 기능을 제공합니다.

- 현재 상영 중인 영화: `보러 가기` 버튼 클릭 시 CGV, 롯데시네마, 메가박스 예매 사이트 선택 탭 표시
- 기존 공개 작품: `보러 가기` 버튼 클릭 시 Disney+ 페이지로 이동
- 개봉 예정작: 작품 정보 확인을 위한 외부 정보 페이지로 이동

### 7. 관련 소식 바로가기

작품 카드의 `관련 소식` 버튼을 누르면 최신 소식 페이지로 이동하며, 해당 작품명을 키워드로 자동 검색합니다.  
이를 통해 사용자는 작품과 관련된 기사만 빠르게 확인할 수 있습니다.

### 8. CSV 데이터 import

`data/works.csv`, `data/articles.csv` 파일에 저장된 데이터를 PostgreSQL 데이터베이스로 import할 수 있습니다.  
브라우저에서 `/import` 경로에 접속하면 CSV 데이터가 DB에 반영됩니다.

## 데이터베이스 개요

본 프로젝트는 PostgreSQL을 사용합니다.

주요 테이블은 다음과 같습니다.

- `users`: 사용자 정보
- `works`: 작품 정보
- `articles`: 기사 정보
- `work_articles`: 작품과 기사 간 관계
- `tags`: 태그 정보
- `article_tags`: 기사와 태그 간 관계
- `bookmarks`: 사용자 북마크
- `notes`: 사용자 메모

또한 기사 카테고리 통계를 확인하기 위한 View를 사용할 수 있습니다.

- `article_category_stats`: 프랜차이즈별, 카테고리별 기사 수 통계
