## 1. 프로젝트 개요

본 프로젝트는 스타워즈와 같은 유명 영화 프랜차이즈의 최신 소식과 작품 정보를 한곳에서 확인할 수 있는 웹서비스를 제작하는 것을 목표로 한다. 사용자는 웹페이지를 통해 프랜차이즈별 최신 기사, 개봉 예정작, 공개 완료 작품, 관련 소식 등을 확인할 수 있으며, Ollama 기반 로컬 AI 도우미를 통해 원하는 정보를 질문 형식으로 탐색할 수 있다.

초기 프로젝트는 PostgreSQL 데이터베이스를 사용하는 구조로 제작되었으나, 다른 PC 환경에서도 쉽게 실행할 수 있도록 최종 버전에서는 JSON 파일 기반 데이터 로딩 방식으로 변경하였다. 이를 통해 별도의 데이터베이스 서버 설치 없이 Flask 웹 애플리케이션만 실행하면 기본 기능을 사용할 수 있도록 구성하였다.

## 2. 아이템 선정 이유

스타워즈와 같은 장수 IP 프랜차이즈는 오랜 역사와 많은 작품 수를 가지고 있다. 영화뿐만 아니라 드라마, 애니메이션, 게임, 도서 등 다양한 매체로 세계관이 확장되면서 입문자 입장에서는 어떤 작품부터 봐야 하는지, 최신 개봉작을 보기 위해 어떤 내용을 알고 있어야 하는지 파악하기가 쉽지 않다.

특히 최근의 대형 프랜차이즈 콘텐츠는 하나의 영화만 독립적으로 소비되는 것이 아니라, 이전 작품이나 다른 매체의 서사와 연결되는 경우가 많다. 따라서 새로운 개봉작이나 공개 예정작을 이해하기 위해서는 관련 작품과 최신 소식을 계속 확인해야 하는 부담이 생긴다.

이러한 문제를 해결하기 위해 프랜차이즈별 작품 정보와 최신 소식을 한눈에 볼 수 있는 큐레이션 웹서비스를 만들고자 했다. 사용자는 이 서비스를 통해 최신 기사, 작품 정보, 공개 상태, 관련 링크를 빠르게 확인할 수 있다.

또한 개인적으로 약 4만 명의 구독자를 가진 스타워즈 영화 관련 유튜브 채널을 운영하고 있다. 영상을 제작할 때마다 새로운 영화, 드라마, 게임, 제작진 관련 소식을 직접 검색하고 정리해야 하는데, 이 과정에서 많은 시간이 소요된다. 따라서 본 프로젝트는 일반 영화 팬뿐만 아니라 영화·프랜차이즈 관련 콘텐츠를 제작하는 유튜버나 블로거처럼 최신 정보를 자주 확인해야 하는 사용자를 주요 대상으로 한다. 이 웹서비스를 활용하면 사전 조사 시간을 줄이고, 필요한 정보를 더 빠르게 찾을 수 있을 것으로 기대했다.

## 3. 사용 기술

* Python
* Flask
* HTML / CSS / JavaScript
* JSON
* Ollama
* Git / GitLab

초기에는 PostgreSQL을 사용했지만, 최종 제출 버전에서는 실행 편의성을 위해 JSON 기반 구조로 변경하였다. 또한 로컬 AI 기능 구현을 위해 Ollama를 사용하였다. Ollama는 외부 클라우드 API를 사용하지 않고 사용자의 PC에서 직접 LLM을 실행할 수 있는 도구이므로, 로컬 환경에서 AI 도우미 기능을 실험하기에 적합하다고 판단하였다.

## 4. 주요 기능

### 4.1 프랜차이즈 탭 기능

웹서비스는 스타워즈와 마블 등 여러 프랜차이즈로 확장할 수 있도록 탭 구조를 제공한다. 현재는 스타워즈 데이터를 중심으로 구성되어 있으며, 데이터의 `franchise` 값을 기준으로 콘텐츠를 구분한다.

### 4.2 최신 소식 조회

수동으로 정리한 기사 데이터를 기반으로 최신 소식을 카드 형태로 제공한다. 각 기사에는 제목, 출처, 게시일, 카테고리, 요약, 원문 링크가 포함된다. 가장 최신 기사는 대표 카드로 크게 표시하고, 나머지 기사는 일반 카드 형태로 보여준다.

### 4.3 기사 검색 및 카테고리 필터링

사용자는 키워드를 입력해 기사 제목, 요약, 출처 등을 검색할 수 있다. 또한 영화, 드라마, 애니메이션, 게임, 도서, 기타 등의 카테고리를 기준으로 원하는 소식만 필터링할 수 있다.

### 4.4 작품 정보 조회

작품 정보 페이지에서는 개봉 예정작, 화제작, 공개 완료 작품 등을 확인할 수 있다. 각 작품은 제목, 유형, 공개일, 공개 상태, 설명, 관련 링크를 포함한다. 상영 중이거나 개봉 예정인 작품의 경우 관련 정보나 예매 사이트로 이동할 수 있도록 구성하였다.

### 4.5 관련 소식 바로가기

작품 카드의 관련 소식 버튼을 누르면 해당 작품명을 키워드로 최신 소식 페이지에서 자동 검색한다. 이를 통해 사용자는 특정 작품과 관련된 기사만 빠르게 확인할 수 있다.

### 4.6 Ollama 기반 AI 도우미

웹페이지 우측 하단에 AI 도우미 챗봇을 추가하였다. 사용자가 질문을 입력하면 Flask 서버가 JSON 데이터에서 관련 기사와 작품 정보를 먼저 검색하고, 해당 내용을 Ollama 로컬 AI 모델에 전달한다. AI 도우미는 전달받은 아카이브 데이터를 바탕으로 한국어 답변을 생성하고, 관련 기사나 작품 링크를 함께 제공한다.

예를 들어 사용자가 “스타워즈 개봉 예정작이 뭐가 있어?”라고 질문하면, 웹서비스는 `status`가 `Upcoming`인 작품을 먼저 찾고, 해당 작품 정보를 기반으로 답변을 생성한다. 이처럼 모든 판단을 AI에게만 맡기지 않고, 중요한 데이터 검색과 분류는 코드에서 먼저 처리하도록 구성하였다.

## 5. 중요한 구현 정보

### 5.1 PostgreSQL에서 JSON 기반 구조로 변경

처음에는 데이터베이스 과목 프로젝트의 연장선에서 PostgreSQL을 사용하였다. 하지만 이 방식은 다른 PC에서 실행할 때 PostgreSQL 서버 설치, 데이터베이스 생성, SQL 파일 실행, 환경 변수 설정 등이 필요하다는 단점이 있었다.

기말 프로젝트의 목적은 다른 사람이 쉽게 실행하고 결과를 확인할 수 있는 실습형 프로젝트에 더 가깝다고 판단하여, 최종 버전에서는 JSON 파일을 직접 읽는 구조로 변경하였다. 이를 통해 별도의 DB 서버 없이도 웹서비스를 실행할 수 있게 되었다.

### 5.2 이미지 용량 문제 해결

작품 포스터 이미지를 로컬 `static/images` 폴더에 저장했을 때 GitLab 저장소 용량 제한 문제가 발생하였다. 이를 해결하기 위해 대용량 이미지 폴더는 Git 추적 대상에서 제외하고, 필요한 경우 외부 이미지 URL이나 수동 입력 데이터를 활용하는 방식으로 변경하였다.

### 5.3 기사 데이터는 수동 큐레이션 방식 사용

스타워즈 최신 소식은 주로 Star Wars News Net과 같은 팬 뉴스 사이트에서 확인할 수 있다. 하지만 이러한 사이트는 일반적으로 공식 API를 제공하지 않기 때문에, 자동 수집 기능은 현재 버전에서는 구현하지 않았다. 대신 기사 제목, 원문 링크, 요약, 카테고리 등을 직접 정리하여 JSON 데이터로 관리하는 방식을 사용하였다.

### 5.4 Ollama 기능은 선택 기능으로 구성

Ollama AI 도우미 기능을 사용하려면 사용자의 PC에 Ollama가 설치되어 있고, 지정된 모델이 실행 중이어야 한다. 다만 Ollama가 실행되지 않아도 최신 소식 조회, 작품 정보 조회, 검색, 필터링 등 기본 웹서비스 기능은 정상적으로 사용할 수 있다. 즉, AI 기능은 프로젝트의 확장 기능이며, 기본 아카이브 기능과 분리되도록 구성하였다.

## 6. 실행 방법

### 6.1 가상환경 생성 및 실행

```bash
python -m venv venv
```

Windows PowerShell 기준:

```bash
.\venv\Scripts\Activate.ps1
```

필요한 패키지 설치:

```bash
pip install -r requirements.txt
```

Flask 서버 실행:

```bash
python app.py
```

브라우저에서 다음 주소 접속:

```text
http://localhost:5000
```

### 6.2 Ollama 실행

AI 도우미 기능을 사용하려면 Ollama 설치 후 모델을 실행해야 한다.

예시:

```bash
ollama run qwen2.5:3b
```

또는 프로젝트에서 설정한 모델명에 맞게 실행한다.

```bash
ollama run llama3.2:3b
```

Ollama가 실행 중이면 웹페이지의 AI 도우미를 통해 질문을 입력할 수 있다.

## 7. 프로젝트를 진행하며 느낀 점

이번 프로젝트를 진행하면서 단순히 웹페이지를 만드는 것보다, 실제 사용 상황을 고려한 구조 설계가 중요하다는 것을 느꼈다. 처음에는 데이터베이스 과목에서 사용했던 PostgreSQL 구조를 그대로 활용했지만, 다른 환경에서 실행하려면 설정이 복잡하다는 문제가 있었다. 최종적으로 JSON 기반 구조로 변경하면서 프로젝트의 완성도는 단순한 기능의 수가 아니라, 얼마나 쉽게 실행되고 유지될 수 있는지와도 관련된다는 점을 배웠다.

또한 Ollama를 연동하면서 AI 기능을 웹서비스에 추가하는 과정도 경험할 수 있었다. 처음에는 AI에게 질문을 그대로 넘기면 충분할 것이라고 생각했지만, 실제로는 AI가 잘못된 정보를 섞어 답변하는 경우가 있었다. 이를 해결하기 위해 질문 의도를 코드에서 먼저 분석하고, 관련 기사와 작품 데이터를 선별한 뒤 AI에게 전달하는 방식으로 수정하였다. 이를 통해 AI 기능은 모델 성능만 중요한 것이 아니라, 어떤 데이터를 어떻게 전달하느냐가 매우 중요하다는 점을 알게 되었다.

개인적으로 스타워즈 관련 유튜브 채널을 운영하면서 최신 정보를 찾고 정리하는 작업을 자주 해왔기 때문에, 이번 프로젝트는 단순한 과제 이상의 의미가 있었다. 실제로 콘텐츠 제작 과정에서 사용할 수 있는 정보 정리 도구의 초기 형태를 만들어본 경험이 되었고, 향후에는 자동 기사 수집, 더 많은 프랜차이즈 지원, 감상 순서 추천, 사용자 북마크 기능 등으로 확장할 수 있을 것 같다.

## 8. 한계점 및 개선 방향

현재 프로젝트는 프로토타입 수준이므로 몇 가지 한계가 있다.

첫째, 기사 데이터는 자동 수집이 아니라 수동 입력 방식이다. 향후에는 RSS나 뉴스 API를 활용하여 최신 소식을 자동으로 갱신하는 기능을 추가할 수 있다.

둘째, 이미지 데이터는 저장소 용량 문제로 인해 로컬 이미지 저장 방식을 제한하였다. 향후에는 외부 이미지 URL이나 TMDB API 등을 활용하여 포스터 이미지를 안정적으로 불러오는 방식을 적용할 수 있다.

셋째, Ollama 기반 AI 도우미는 로컬 모델의 성능에 따라 답변 품질이 달라진다. 향후에는 더 성능이 좋은 모델을 사용하거나, RAG 구조를 적용하여 더 정확한 답변을 제공할 수 있다.

넷째, 현재는 스타워즈 데이터를 중심으로 구성되어 있지만, 마블, DC 등 다른 프랜차이즈 데이터도 추가하면 더 범용적인 영화 프랜차이즈 정보 서비스로 확장할 수 있다.

## 9. 마무리

본 프로젝트는 유명 영화 프랜차이즈의 최신 소식과 작품 정보를 한눈에 확인할 수 있는 아카이브 웹서비스를 만들고, 여기에 Ollama 기반 로컬 AI 도우미를 결합한 실습형 프로젝트이다. 단순한 팬페이지가 아니라, 최신 정보 탐색 시간을 줄이고 사용자가 원하는 기사나 작품 정보를 빠르게 찾을 수 있도록 돕는 도구를 목표로 제작하였다.

이번 프로젝트를 통해 Flask 웹 개발, JSON 기반 데이터 관리, Git 저장소 관리, 로컬 AI 연동, 사용자 중심 기능 설계 등을 함께 경험할 수 있었다.
